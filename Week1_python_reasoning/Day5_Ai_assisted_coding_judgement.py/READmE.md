### 💫 Day 5: AI-assisted coding judgment

Main skill

> You should use AI, but not blindly trust it.

Your roadmap says: ask AI to generate code, then review correctness, edge cases, and failure modes.

That means your job is not:

> AI wrote code, so I copied it.

Your job is:

> AI wrote code, so I tested it, broke it, checked assumptions, and improved it.

### 🧠my main job is :
- Is this code actually correct?
- What assumptions did it make?
- What inputs break it?
- Does it fail clearly or silently?
- Can I improve it?

### 🎯The Day 5 Review Formula

Whenever AI gives you code, review it with this checklist:

1. What is the function supposed to do?
2. What input does it expect?
3. What output does it return?
4. Does it work for normal input?
5. What happens with empty input?
6. What happens with None?
7. What happens with wrong types?
8. What happens with extreme or unusual values?
9. Does it fail clearly?
10. Can I make it safer or more readable?

This is your AI code judgment framework.
