## 💫Week 1 Mini Task: CSV Summary Tool

This script loads a CSV file, validates required columns, and prints basic summary statistics.

### What it checks

- Number of rows and columns
- Column names
- Missing values
- Numeric summary statistics

### Failure modes

- CSV file path may be wrong
- Required columns may be missing
- Numeric columns may contain invalid values
- Missing values may affect summary statistics

### 👨‍🦳 Day 6 lesson

- Good code fails early and clearly.
- Bad code fails later and confusingly.
